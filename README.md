# SmartCart – Customer Segmentation & Analytics

SmartCart is a data analytics and machine learning project that focuses on customer segmentation using unsupervised learning techniques. The project analyzes customer behavior data, performs extensive preprocessing and exploratory data analysis (EDA), and identifies distinct customer groups to help businesses make data-driven marketing decisions.

---

## Project Overview

Understanding customer behavior is essential for businesses to improve marketing strategies, customer retention, and sales performance.

This project applies machine learning clustering algorithms to segment customers based on purchasing patterns and demographic features. The resulting customer groups can be used for targeted promotions, personalized recommendations, and strategic business planning.

---

## Workflow

1. Load and inspect customer dataset
2. Handle missing values and data inconsistencies
3. Perform feature engineering and encoding
4. Scale numerical features
5. Conduct exploratory data analysis
6. Apply clustering algorithms
7. Determine optimal clusters using Elbow Method
8. Evaluate clustering quality using Silhouette Score
9. Visualize customer segments
10. Generate business insights

---

## Machine Learning Models

### K-Means Clustering

Used to partition customers into distinct groups based on similarity in purchasing behavior and demographic characteristics.

### Agglomerative Clustering

Applied hierarchical clustering to compare segmentation results and uncover customer relationships.

---

## Evaluation Metrics

* Elbow Method
* Silhouette Score

These metrics were used to determine the optimal number of clusters and assess clustering performance.
